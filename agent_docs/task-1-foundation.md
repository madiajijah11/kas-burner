# Task 1: Project Foundation & WASM Setup

## Goal
Set up Vite React TypeScript project with Tailwind CSS and `kaspa-wasm` support.

## Acceptance Criteria
- Vite project bootstrapped with React and TypeScript.
- Tailwind CSS installed with dark background, monospace fonts, and Kaspa cyan accent.
- `kaspa-wasm` dependency installed and configured with `vite-plugin-wasm` & `vite-plugin-top-level-await`.
- `npm run dev` compiles without errors.
